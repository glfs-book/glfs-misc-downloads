# glfs-misc-downloads

This repository is for hosting downloads that are not hosted by anyone else or
in the books made by the GLFS development team. These can include binary
downloads of certain packages, like OpenJDK. This repository will not host
patches. The main reason for not including the files that will be in this
repository in the respective books is it would inflate book download size both
for Git, and releases. It would also take up more site on the GLFS pages sites.
